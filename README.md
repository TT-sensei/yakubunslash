# 約分クロスバスターズ

分数のペアと「割る数」を選んで約分していく、約分練習ゲームです。約分できないペアも混ざっているので、「約分できるかどうか」から自分で判断します。

## 公開ページ

[GitHub Pagesで開く](https://tt-sensei.github.io/yakubunslash/)

## 遊び方

1. 約分できるペアを2つタップする
2. 両方を割れる「割る数」を選ぶ
3. 約分できないペアを選ぶとミスになる

- レベルはLV.1〜LV.5。レベルが上がると扱う数が大きくなります（分母の目安：LV.1は6〜24、LV.5は〜80）
- 結果画面でスコア・正答率・最大コンボを確認できる
- 学習を進めるとバッジコレクションが増えていく

## 対象

小学校5〜6年生（発展）。分数の約分に慣れてきた子向けです。

「約分マスター・クラッシュ！」（yakubuncrash）が約分できる分数を見抜いてタップする判断型なのに対し、こちらはペア選びと割る数選びの2段構えで、約分の手順そのものを練習する形式です。

## 技術メモ

- `index.html` の単一ファイルで動作し、ビルド不要
- バッジなどの記録は端末内（localStorage）に保存
